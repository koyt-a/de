# Инструкция по адаптации шаблона на экзамене

Этот шаблон спроектирован так, чтобы вы могли настроить его под любой вариант задания (косметика, игрушки, электроника, обувь и т.д.) **без изменения основного кода приложения**.

Следуйте этим шагам строго по порядку.

### 1. Подготовка файлов
- [ ] Переместите предоставленные Excel-файлы (с данными о товарах, пользователях и пунктах выдачи) в папку `data/`.
- [ ] Скопируйте все фотографии товаров в папку `images/`.
- [ ] Поместите файл иконки или логотипа (например, `icon.png` или `logo.ico`) в корень проекта.

### 2. Настройка конфигурации (`config.py`)
Откройте файл `config.py`. В нём находятся все основные настройки, включая дизайн.
- [ ] В блоке **ОСНОВНЫЕ НАСТРОЙКИ** измените:
  - `APP_NAME` — название магазина (например, `"ООО Обувь"`).
  - `DB_NAME` — название файла базы данных (например, `"shoe_store.db"`).
  - `ITEM_NAME_SINGULAR` и `ITEM_NAME_PLURAL` — терминология (например, `"Товар"` / `"Товары"`).
- [ ] В блоке **НАСТРОЙКА ТАБЛИЦЫ ТОВАРОВ** измените список `PRODUCT_COLUMNS` в соответствии с тем, какие колонки требуются в вашем задании для отображения в интерфейсе.
- [ ] В блоке **НАСТРОЙКА ДИЗАЙНА** укажите требуемые цвета и шрифт:
  - `FONT_FAMILY` — основной шрифт (например, `"Times New Roman"` или `"Comic Sans MS"`).
  - `BG_PRIMARY`, `BG_SECONDARY`, `COLOR_ACCENT` — цвета фонов и акцентов (укажите HEX-коды из задания).
  - `DISCOUNT_THRESHOLD` и `COLOR_DISCOUNT_HIGH` — настройка выделения товаров с большой скидкой.

### 3. Настройка импорта базы данных (`tools/build_db.py`)
Чтобы Excel-файлы правильно загрузились в базу данных, скрипт импорта должен знать точные названия колонок в таблицах.
- [ ] Откройте файл `tools/build_db.py`.
- [ ] Найдите словари `COLUMNS_PRODUCT`, `COLUMNS_USER`, `COLUMNS_ORDER` (находятся в самом начале файла).
- [ ] Замените ключи в этих словарях на те названия колонок, которые написаны в **ваших** Excel-файлах (обращайте внимание на пробелы и регистр букв).

### 4. Установка логотипа и сборка базы данных
- [ ] Запустите скрипт установки иконки:
  ```bash
  python tools/set_icon.py
  ```
  Выберите файл иконки, который вы положили в проект. Скрипт сам обрежет его и сохранит в нужном формате.
- [ ] Запустите скрипт сборки базы данных:
  ```bash
  python tools/build_db.py
  ```
  Отвечайте на вопросы в консоли (нужно будет поочередно выбрать Excel-файлы из папки `data/`).

### 5. Финальная проверка
- [ ] Запустите приложение:
  ```bash
  python main.py
  ```
- [ ] Авторизуйтесь от имени Администратора (логин и пароль возьмите из вашего Excel-файла с пользователями).
- [ ] Проверьте, что дизайн (цвета и шрифты) применился успешно.
- [ ] Дважды кликните по товару в таблице и убедитесь, что его фотография загружается корректно.

---
**💡 Совет:** Если вы ошиблись при импорте или в базе задвоились данные, просто удалите файл `.db` из папки проекта и запустите `python tools/build_db.py` заново.
