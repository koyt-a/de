# Универсальный шаблон настольного приложения для магазина

## 1. Описание
Это готовый шаблон настольного приложения на Python (tkinter) для управления магазином или каталогоми. Его можно легко адаптировать под любой магазин (одежда, игрушки, электроника и т.д.), редактируя только файлы конфигурации без необходимости менять основной код приложения.

## 2. Стек технологий
| Компонент        | Технология              |
|------------------|-------------------------|
| Язык             | Python 3.10+            |
| GUI              | tkinter + ttk (встроен) |
| База данных      | SQLite (встроен)        |
| Импорт Excel     | pandas + openpyxl       |
| Графика          | Pillow                  |

## 3. Структура проекта
```
shoe_store/
├── config.py                # Главный конфигурационный файл шаблона
├── main.py                  # Точка входа — запуск приложения
├── requirements.txt         # Зависимости (pandas, openpyxl, Pillow)
├── README.md                # Данный файл
├── assets/                  # Папка для иконок приложения
├── data/                    # Сюда кладём Excel-файлы для импорта
├── images/                  # Фотографии товаров
├── database/
│   ├── __init__.py
│   └── db.py                # Подключение к БД и SQL-запросы
├── tools/
│   ├── build_db.py          # Интерактивный скрипт сборки базы данных
│   └── set_icon.py          # Скрипт установки иконки приложения
└── ui/
    ├── __init__.py
    ├── login.py             # Окно авторизации
    ├── products.py          # Окно товаров
    └── orders.py            # Окно заказов
```

## 4. Быстрый старт (для экзамена)
1. Установите Python и зависимости: `pip install -r requirements.txt`
2. Положите ваши Excel-файлы в папку `data/`
3. Запустите сборку БД: `python tools/build_db.py` (интерактивно выберите файлы)
4. Запустите приложение: `python main.py`

## 5. Как адаптировать шаблон под другое задание
Следуйте этому чеклисту для адаптации:
- [ ] 1. Открой `config.py` — поменяй основные названия (`APP_NAME`, `DB_NAME`, `ITEM_NAME`) и **настройки дизайна** (шрифты, цвета) согласно вашему заданию.
- [ ] 2. В `config.py` поменяй `PRODUCT_COLUMNS` под колонки твоей таблицы
- [ ] 3. В `tools/build_db.py` поменяй словари `COLUMNS_PRODUCT`, `COLUMNS_USER`, `COLUMNS_ORDER` под названия колонок в твоих Excel-файлах
- [ ] 4. Запусти `tools/set_icon.py` чтобы установить иконку
- [ ] 5. Скопируй фото товаров в папку `images/`
- [ ] 6. Запусти `tools/build_db.py` — выбери свои Excel-файлы
- [ ] 7. Запусти `main.py` — проверь что всё работает
- [ ] 8. Готово

## 6. Как изменить дизайн (Цвета и Шрифты)
Вам не нужно менять код самих окон, чтобы перекрасить приложение! Все визуальные настройки собраны в `config.py` в блоке `НАСТРОЙКА ДИЗАЙНА`.
1. Откройте `config.py`.
2. Измените `FONT_FAMILY` (например, на `"Times New Roman"`, если это требуется в задании).
3. Укажите HEX-коды для фонов (`BG_PRIMARY`, `BG_SECONDARY`) и акцентов (`COLOR_ACCENT`).
4. Настройте порог и цвет для выделения товаров с большой скидкой (`DISCOUNT_THRESHOLD` и `COLOR_DISCOUNT_HIGH`).
5. Перезапустите приложение, и новый дизайн применится ко всем окнам автоматически.

## 7. Как сменить иконку
1. Скопируй файл `.ico` или `.png` в любую папку проекта
2. Запусти `python tools/set_icon.py`
3. Выбери файл из списка
4. Готово — иконка применится ко всем окнам, а также появится вместо логотипа в левом верхнем углу.

## 8. Как добавить фото товаров
1. Скопируй файлы изображений в папку `images/`
2. Убедись что имена файлов совпадают с полем «Фото» в Excel-таблице товаров
3. При двойном клике на товар — фото появится автоматически

## 9. Роли пользователей
| Роль          | Вход          | Товары                      | Заказы                 |
|---------------|---------------|-----------------------------|------------------------|
| **Гость**     | Без авторизации | Только просмотр            | Нет доступа            |
| **Клиент**    | Логин/пароль  | Только просмотр             | Нет доступа            |
| **Менеджер**  | Логин/пароль  | Просмотр + фильтры + поиск | Только просмотр        |
| **Администратор** | Логин/пароль | Полный CRUD + фильтры  | Полный CRUD            |

## 10. Тестовые логины
Для получения данных авторизации откройте файл `user_import.xlsx` (или ваш эквивалентный файл). Там указаны логины, пароли и соответствующие им роли. При нажатии «Войти как гость» авторизация не требуется.

## 11. Частые ошибки

### ❌ `ModuleNotFoundError: No module named 'pandas'`
**Решение:** Выполните `pip install -r requirements.txt`

### ❌ Окно не открывается / ошибка tkinter
**Решение:** Убедитесь, что установлен Python из [python.org](https://www.python.org), а не из Microsoft Store (у магазинной версии могут отсутствовать модули GUI).

### ❌ `sqlite3.IntegrityError: UNIQUE constraint failed`
**Решение:** База данных уже содержит данные. Удалите файл базы данных и запустите `build_db.py` снова.
